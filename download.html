คุณสมบัติเด่นของ Romarco

ออกแบบและปรับแต่งสถาปัตยกรรมระดับ Native เพื่อความลื่นไหลสูงสุดบนโทรศัพท์ทุกระดับสเปก

🎯

Multi-Target Sequence

ตั้งจุดคลิกลำดับขั้นตอน #1, #2, #3 ได้ไม่จำกัด สามารถลากวางบนหน้าจอ และกดตั้งเวลาดีเลย์รายจุดได้อย่างอิสระ

🧠

Pure Native & Ultra-Light

พัฒนาด้วย Kotlin + Android SDK 100% ปราศจาก Framework หนักๆ ทำให้ขนาดไฟล์เล็กเพียง 5MB และขณะรันใช้งาน RAM เพียง ~15–25 MB เท่านั้น ไม่กินทรัพยากรเกม

🔋

Zero-Overhead Engine

ใช้ระบบ Coroutine Event-driven ที่คืนรอบ CPU ทันทีระหว่างรอดีเลย์ พร้อมปิดการสแกนหน้าจอที่ไม่จำเป็น ทำให้เครื่องไม่ร้อน และประหยัดพลังงานแบตเตอรี่ได้สูงสุด

🛡️

Foreground LMK Protection

มีระบบ Foreground Service พร้อมการแจ้งเตือน ป้องกันระบบจัดการแรม (Low Memory Killer) ของ Android ปิดแอปทิ้งขณะเปิดเกมฟาร์มยาวๆ

🎮

Floating Overlay Controller

เมนูลอยขนาดกะทัดรัดแสดงทับหน้าจอเกม ควบคุมได้ง่ายด้วยปุ่ม Play ▶, Pause ⏸, เพิ่มจุดคลิก ➕, ลดจุดคลิก ➖ และปุ่มซ่อนเมนูได้อย่างสะดวก

⚙️

ไม่จำเป็นต้อง Root เครื่อง

ทำงานผ่าน Accessibility Service API มาตรฐานความปลอดภัยของระบบ Android โดยตรง ปลอดภัย ไม่ต้องปลดล็อกระบบหรือเสี่ยงต่อความปลอดภัยของโทรศัพท์

📖

วิธีติดตั้งและเปิดใช้งาน (ครั้งแรก)

ทำตามขั้นตอนง่ายๆ 4 ขั้นตอนเพื่อเริ่มใช้งาน

1 ดาวน์โหลดและเปิดไฟล์ APK

กดปุ่มดาวน์โหลดไฟล์ Romarco_AutoClicker_v1.0.apk จากหน้านี้ลงในมือถือ Android แล้วแตะเปิดไฟล์

2 อนุญาตให้ติดตั้งจากแหล่งนี้

หากระบบขึ้นเตือนความปลอดภัย ให้กด "การตั้งค่า (Settings)" แล้วเปิดสวิตช์ "อนุญาตจากแหล่งที่มานี้ (Allow from this source)"

3 เปิดสิทธิ์การทำงาน 2 อย่าง

เมื่อเปิดแอป Romarco ให้กดเปิดสิทธิ์:
• แสดงทับแอปอื่น (Draw over other apps)
• บริการการเข้าถึง (Accessibility Service)

4 เริ่มสร้างชุดคำสั่งในเกม

กดปุ่ม "เริ่มใช้งานมาโคร" เมนูลอยจะปรากฏขึ้น สลับเข้าเกมแล้วกดปุ่ม ➕ เพื่อเพิ่มจุดคลิกตามปุ่มสกิล แล้วกด ▶ เพื่อเริ่มทำงานทันที!
